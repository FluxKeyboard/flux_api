# Blender Shortcut Context Switcher

This project shows how you can use the Polymath API to programatically update a shortcut sets current context.

The project utiizes the different workspace names in Blender, and the project is thoroughly documented so that, in combination with the API documentation, you should be able to get a good understanding of how to build your own 3rd party plugin for Polymath

If you wish to utilize the Blender add on, zip up this folder and add it from disk in Blender preferences
