# Graph and Grid Demo

This project is a more in depth showcase of what is possible with the generic graphs and grids. It will connect to your Polymath, and sned through three sets of data. Stocks, garden statistics, and Factorio statistics. For ease of use this example stores the API key inside your flux config folder. If you are wanting to make a plugin to share with others, we reccomend storing the API key inside the operating systems secret storage instead. Examples on how to do this can be found in the other three

# Setup

To run this you'll need to set up a quick flutter project and install the following packages. The versions are listed but the newest version should work

dependencies:
http: ^1.6.0
http_io: ^3.0.0
logging: ^1.3.0

dev_dependencies:
path: ^1.9.1
