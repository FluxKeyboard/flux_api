# GenericTileCreationRequest

## Properties

| Name       | Type                  | Description                                                                                    | Notes                              |
| ---------- | --------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------- |
| **title**  | **String**            | The title of the created tile. The ID will be directly comparable to the title               |                                    |
| **type**   | **GenericModuleType** | The type of generic tile you wish to create                                                  |                                    |
| **index**  | **int**               | The position in the top bar you want the tile to be placed. Must be a number between 0 and 3 |                                    |
| **length** | **int**               | How large you want the x axis on the graph tile to be, limited to 100,000                     | Only required for the graph tile |
